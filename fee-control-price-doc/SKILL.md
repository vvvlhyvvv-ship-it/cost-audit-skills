### S3 算数（Decimal 精算，不用 float）
人日法公式：
```
直接人工成本 = Σ(各职级人日单价 × 人日数)
编制费 = 直接人工成本 × 人工日法综合计算系数
取定   = 取整至百元（或千元）
```
反解技巧：给定目标金额 T，需 `Σ = T / 系数`，再配职级人日凑整数。
例：目标 6.5 万，系数 2.44 → Σ 需 26,640 元 → 3000×1＋2210×6＋1730×6 = 26,640 → ×2.44 = 65,001.60 → 取整 65,000.00。

**必须独立复算**：新建脚本重算并 `assert`，不复用构建脚本的中间变量。

### S4 生成三件套
运行 `scripts/make_fee_doc.py`（顶部 CONFIG 改项目信息与金额）。脚本做三件事：
1. 复制母本封皮／编制说明 → `set_para_text()` 整段写 run0、清空其余 run（保住原字体）；
2. **删除尾部空段落**（母本自带 2 个尾部空段，内容增行后会多出空白页）；
3. 重建计费清单 xlsx（母本列结构 7 列：序号／工作阶段／人员类别／人日单价／人日数／金额／备注；同阶段纵向合并）。

### S5 导出合并 PDF
运行 `scripts/make_fee_pdf.py`：win32com 调 Word（FileFormat=17 导 PDF）与 Excel（ExportAsFixedFormat(0,…)，横向＋FitToPages 1×1）→ pymupdf `insert_pdf` 合并。
**导出后必须逐页渲染成 PNG 目视复核**（`_render.py`），确认：页数为 3、无空白页、无文字溢出列宽、金额与大写一致。

## 4. 关键坑（踩过）

1. **母本依据已废止**——照抄母本文号会被审出硬伤，务必换现行依据。
2. **尾部空段 → 空白页**——编制说明内容比母本长就会溢出一页；改完字务必删尾部空段。
3. **表格列宽溢出**——工作阶段列放长句（如"编制费＝直接人工成本×综合计算系数"）会截字，列宽 ≥32 或缩短文案。
4. **编制说明必须单页**——母本正文 16pt、行距大，一页只容约 18 行；依据条目要精简（≤10 行）。
5. **母本 .docx 文字分散在多个 run**——用"整段写 run0 + 清空其余"最稳，别做子串级替换。
6. **本机 shell**：Bash 工具自带 shell 缺 `grep`/`head`/`dirname`，需 `"/c/Program Files/Git/bin/bash.exe" -lc '…'` 包一层；PowerShell 工具不回显 stdout，用 `Set-Content` 落文件再读。
7. **PDF 工具链**：本机 Word 16.0 可用、无 LibreOffice；`win32com` + `pymupdf` 已装在托管 venv `C:\Users\lihaoyuan\.workbuddy\binaries\python\envs\default`。
8. **同一规格不存两处**——版式数字只在母本与本技能各一份；引用时指向母本实测，不复制到别的技能。
