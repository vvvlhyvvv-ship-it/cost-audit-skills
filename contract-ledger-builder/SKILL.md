# 合同价格台账构建与整改

> 本 Skill 固化「价格数据整理·合同台账」项目（2026-10，133 份合同/4,025 行明细）的完整工作流：
> 从 648 个散落源文件到双版本 Excel 台账（xlsx 数据 + xlsm 联动宏），含批次化整改（电话清洗/材料名回源/补抽入账/版本去重/cosmetic）与全量自验。
> 适配场景：造价工程师把施工/采购合同资料整理成可勾稽、可检索、可联动的价格台账。

---

## ⛔ 环境铁律（本机实测，违反必踩坑）

1. **Excel/Word COM 操作必须走 PowerShell 通道**。Bash 沙箱会拦截 win32com 的 SaveAs（临时文件路径被改写为 `<盘>:\//<8位hex>`，任何目标路径均失败，报"不能访问文件"）。PowerShell 通道正常。
2. **openpyxl 写新行不继承样式**。入账/追加行必须逐格复制既有行样式（`copy(src.font/border/fill/alignment)` + `number_format`），否则新行字体/边框/数字格式与全表不一致（曾导致 2,136 行明细字体错乱被用户截图指出）。
3. **openpyxl delete_rows 不更新公式/条件格式/数据验证范围**。删行后必须手工修正 autofilter.ref、CF 的 sqref 与公式内行号、DV 的 sqref。
4. **Git Bash 会把反斜杠路径转成正斜杠**传给 Windows 程序。脚本内路径用 `r'...'` 原生命令串，不经 argv 传递。
5. **写数值用 Decimal，不用 float**（float 产生 0.000000001 级假偏差，也掩盖真实分位尾差）。勾稽容差：单价 0.01 元、总价 0.05 元。

## 一、何时使用

- 用户有一堆合同文件（docx/doc/pdf/扫描 jpg/xls），要整理成价格台账；
- 台账已存在，要补抽漏账合同、清洗错误数据（电话/材料名/转义符）、版本去重；
- 需要对台账做勾稽自验（单价×税率、分表合计=总价、删前-删条=删后）。

不适用：单纯写审核报告公文（用 `cost-audit-doc-writer`）、单纯排版 Word（用 `gongwen-doc-format`）。

---

## 二、输入清单（开工前清点）

1. **源文件树**：按项目/供应商分文件夹；统计文件总数与类型分布；
2. **既有台账**（如有）：xlsx/xlsm 双版本、审查基线文件（`_审查_*`，禁止覆盖）；
3. **整改指令**（如有）：逐合同给死改法的指令文件优先于自行推断。

## 三、工作流（五阶段，批次化执行）

### 阶段 0：备份留证（铁律，缺失视为未开工）

复制既有台账为 `_整改前备份N_<日期>.xlsx/.xlsm`，md5 一致后留证。**每批大改前都备份**。

### 阶段 1：源文件 ingestion

| 源类型 | 处理方法 | 坑 |
|---|---|---|
| .doc | Word COM `SaveAs(FileFormat=16)` 转 .docx，**PowerShell 通道** | 转换前先查是否已有转换件（`_doc转换_调研` 镜像目录），避免重复转换 |
| .docx | 正则直读 `word/document.xml` 的 `<w:t>`（管线）或 python-docx（核验） | **必须 XML 实体反转义**：`&lt;`→`<`、`&gt;`→`>`、`&quot;`→`"`、`&apos;`→`'`、**`&amp;` 最后替换**（防 `&amp;lt;` 二次转义错序） |
| 扫描 jpg/png | RapidOCR；低置信度区域**渲染高 DPI 重识别 + 原图目验** | OCR 尾数有 1/4 残差（139…91 vs 94）、多字少字误读——**录入前必须对照原图人工确认** |
| .pdf | PyMuPDF 取文本层 | 文本层长度=0 即扫描件，**显式报错不静默跳过**（损坏 PDF 是前车之鉴） |
| .xls/.xlsx | pandas/openpyxl 直读 | 比价单类机读文件通常无电话信息，别指望 |

### 阶段 2：内容抽取（管线 + 校验）

- **供应商**：乙方条款正则（`乙方[：:]`、`供应单位[：:]` 等模式）+ 单位后缀白名单。**后缀表要全**：有限公司/经营部/经销部/**经销处**/厂/商行/门市部…（"经销处"曾漏掉导致供应商未识别）；排除银行/金融机构词。
- **电话/联系人**：11 位手机号正则（前后非数字防账号片段误匹配）+ **甲乙方方位校验**：号码前后 50 字内出现"甲方/身份证/家属/招标代理/代理机构"即拒收。人名过"标签词语素"正则（电话/手机/号码/联系/身份/家属/有限/公司…），纯精确匹配黑名单必然漏。
- **价目表**：表头关键词定位列（名称/规格/单位/数量/单价/税率/合计）；**含税/除税口径看列头前缀**——"含税材料单价+含税人工单价"结构须合并为含税、除税由合同税率换算；"除税单价"结构才可直接取除税（曾把含税材料单价误填除税列，导致全库勾稽崩坏）。
- **合同总价**：合计行/总计行 + 正文金额候选取最大者；大写金额（"肆拾玖万捌仟…"）可作交叉验证；多表合同总价=各分表合计之和。
- **合计行过滤要含"总合计"**：`^(总?合计|小计|总计|大写|备注)`——"总合计"开头的行曾泄漏成明细行。

### 阶段 3：台账构建（双版本 + 宏）

1. openpyxl 改 xlsx：**旧值断言不符即中止**（fail-fast）；保护行（已修正项）任何情况下不得再动；
2. **新行逐格复制样式**（见环境铁律 2）；数字格式：单价 `#,##0.00`、税率 `0%`；
3. 公式用 `HYPERLINK + MATCH` 跨表联动（按合同号动态匹配——**重排序号后自动有效**，无需改公式）；
4. win32com 打开 xlsx → `SaveAs(FileFormat=52)` → 注入 ThisWorkbook 宏 → Save，**PowerShell 通道**；
5. 宏验证：zip 内 `xl/vbaProject.bin` 存在 + `[Content_Types].xml` 含 `macroEnabled.main`。

### 阶段 4：版本定版去重（用户规则，2026-10 定）

- **带"未调整/旧/退回"标注 = 初版/作废版，不入账**；
- **带"最终/最新/-新"标注 = 最终版，入账**；无标注的主目录文件 = 默认最终版；
- **"新建文件夹"只是文件夹名，不算版本标注**；
- **"-新"与"-最终"并存时取"-最终"**；
- 能按常规逻辑准确判断的，直接按判断归集；**判断不了的先问用户，不猜**；
- 去重执行：删旧版行（汇总+明细同步）→ 重排序号 → **出旧→新序号对照表**（历史引用可追溯）→ 保留行备注注明"另有旧版X（金额Y）已按版本规则剔除"；
- 序号方案：重排（干净但历史引用移位，需对照表）vs 保留空档（引用稳定）——**问用户拍板**。

### 阶段 5：自验（每批必做，写 `_自验_批次X_<时间戳>.log`）

**禁止覆盖 `_审查_*` 基线文件**；自验输出一律 `_自验_*`。

| 检查项 | 方法 |
|---|---|
| 金额勾稽 | 删前总额 − 删条金额 = 删后总额，分文不差 |
| 明细行数 | 汇总"明细行数"列 vs 明细实际行数，逐合同 0 不符 |
| 单价勾稽 | 含税 = 除税 × (1+税率)，Decimal 容差 0.01 |
| 序号连续性 | 汇总/明细序号列严格 1..N |
| 合同号映射 | 明细合同号全在有效范围；**逐合同行数与备份勾稽**（注意：重排后新序号会复用旧删号数字，"号在删号集合中"不是残留，正确验证是行数勾稽） |
| 电话列 | 11 位正则 + 方位校验 0 命中；坏号只允许出现在备注列且带"已删/已改"结论标注 |
| 实体残留 | `&amp;/&lt;/&gt;` 全表 0 残留 |
| 双版本 | xlsx/xlsm 数据列 **repr 级 0 差异** |
| 宏载体 | vbaProject.bin + macroEnabled |
| 保护行 | 按内容定位（不按序号）核对未动 |

**每批交 `_变更清单_批次X.tsv`**（列：工作表/行定位/列名/旧值/新值/依据），用户复核后再开下一批。

## 四、报数纪律（用户明确要求，2026-09 立）

- **报数三件套**：数字 + 口径 + 来源，三项齐了才算报完；
- **三级标注**：✅实测（有时间戳/脚本输出佐证）、⚠️估算（必须标"估"请用户校准）、❓待核（禁用，补测前不许出现在输出里）；
- **跑批时间 ≠ 总耗时**；不许把估算说成实测；记忆里的数字一律当"待核"，能重算的一律重算；
- **取整方向保守**：73 分钟不说"一小时"；
- **归因与事实同级取证**：只有现象没有机制时写"机制未确认"，不给听起来合理的解释；探测失败 ≠ 事实不存在；命令"成功"但落到同名程序上不是事实——凡结论与预期不符，换独立通道复核并写明"探测方法+原始输出"。

## 五、已知坑速查（本项目实测）

| 坑 | 现象 | 解法 |
|---|---|---|
| Bash 沙箱拦 COM | SaveAs 报"不能访问文件 E:\//xxxx" | PowerShell 通道跑 win32com |
| 新行无样式 | 字体 Calibri 11/税率 0.03/无边框 | 逐格 copy 既有行样式 |
| delete_rows 不更范围 | autofilter/CF/DV 指向旧行数 | 手工修正 sqref 与公式行号 |
| parse 返回元组 | `len(parse_detail_tables(...))` 恒为 2 | 解包 `(rows, tax)` |
| 追加行 off-by-one | 序号初值取 max_row 而非最后序号，首行留空 | 序号初值 = 最后序号值；写后断言连续性 |
| 对照表重建 | 删行后按旧行号读数据全错位 | 用**备份文件**取旧数据 |
| 金额 None | 据实结算类合同无总价 | 格式化判空，勿直接 `:,.2f` |
| OCR 尾数残差 | 91/94、多字少字 | 原图目验后才录 |
| 重排复用删号 | 自验"删号残留"误报 | 验证改为逐合同行数勾稽 |
